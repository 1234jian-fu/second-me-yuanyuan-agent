## Design Direction

- Visual theme: Organic Minimalist AI.
- Mood: quiet presence, soft minimalism, private journal, warm daylight.
- Primary canvas: warm cream `#fbf9f5`.
- Primary action: sage green `#566342` / `#a3b18a`.
- Secondary surfaces: mist blue `#d5e1e8`, beige `#ebe1d6`, low container `#f5f3ef`.
- Typography: Manrope-like rounded modern sans.
- Shape: generous 24-32px rounded cards.
- Depth: low-opacity ambient shadows, no harsh elevation.
- Decoration: subtle plant / wave silhouettes as background watermarks.
